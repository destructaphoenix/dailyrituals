Emberfield — the Windfall hero

Emberfield is the sixth Plus hero and the fifth built from live footage: a windswept dusk field plays full-bleed behind the streak — storm-grey sky over dried gold grass, a bare seed-pod tree caught in the wind, embers drifting past. One clip serves day and night alike; the frame is already dusk-lit and doesn't have a brighter counterpart to cut to. Numeral, caption, scrim and XP bar are the layout the other five heroes share.

Accents lift straight off the footage. The grass and the drifting embers are already the warmest thing in frame — gold through amber to a deep ember brown — so the numeral, caption and XP bar run that ramp rather than an unrelated accent. Day and night differ only in scrim depth and how far into that ramp the type sits, the same way Event Horizon's two cards differ.
The crop. Source is 720×1280 portrait, 6.0s; the hero zone is 412×336, so object-fit:cover at object-position:50% 58% shows a band centred just above the horizon — storm cloud for the numeral to sit on, the grass line and seed-pod branch inside the scrim. Nothing is scaled or masked beyond the crop.
The loop is plain. The source already loops cleanly, so each card is a single <video autoplay loop muted playsinline> — no offset copy, no crossfade.
