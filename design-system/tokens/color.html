Color

Every colour token makeTheme() produces, for all eight shipped accent sets in both modes. Generated from src/theme.js — never hand-copied.

Return colours by token name, never by hex. Every swatch below is labelled with the name the app uses (c.accentSoft), and no hex appears anywhere in this page's readable content — the values reach the browser only as CSS custom properties. A spec that names hex codes cannot be ported, because these values change whenever the user picks a different palette.
Night mode is not "day, darker". c.accentDeep flips meaning: on a dark canvas the brighter shade is what gives contrast, so night maps both accent tokens to the same base accent, and c.accentSoft becomes a near-black tint rather than a pastel. Compose with the token, not with a remembered colour.
